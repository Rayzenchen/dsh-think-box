# 思维链显示增强

![抽象示意图：左侧收起的思考框（思考入口、宽行内推理窗、查看译文按钮），右侧展开的思考框（chevron、正文内容与滚动条）](preview.svg)

插件只做两件事：**思考框**和**思考翻译**。答案正文不做任何插件特效，直接由 Harness 的 Markdown 组件渲染；替换内置 `assistant-step` 行只是为了承载思考框。

## 思考框

推理内容显示在「思考」行右侧的行内窗：默认三行，点击展开完整 body（最多 18 行，内容短时按内容收缩），再点收起。思考结束回卷到开头并收成一行，每段只播一次；恢复历史不重播。推理文本按固定 `balanced` 节奏逐字揭示，对数淡入固定开启；系统「减少动效」下两者自动跳过。

## 翻译与模型路由

思考行右侧可切换「查看译文 / 查看原文」，后端二选一：

- **官方组合包**：在插件页启用「思考过程翻译」组合包后由它决定服务；
- **模型路由（llm）**：翻译通道提供与输入框模型菜单一致的选择器——一行摘要（服务商 · 模型 · 推理强度），点开是按服务商分组的模型列表、搜索框与推理强度列表。选择只暂存，点翻译通道的保存才写入。

流式期间只翻译已完成的片段，末尾保持原文；历史思考块始终手动。

## 设置卡

插件页的**设置卡始终展开、无需点击**，页面由「插件说明 / 详情示意图」和这张卡组成。卡片有三项：**启用**、**自动跟随思考**、**翻译通道**（后端、模型路由、目标语言、分片上限、自动翻译；`maxTokens` / `timeoutMs` 只在 `translation.json` 种子里）。`enabled` / `thinkAutoExpand` 写在 profile 的 `cordis.patch.yml` 条目里并即时生效；翻译设置写在 `~/.dsh/think-box/translation.json`。

启用翻译意味着思考文本会发送到你选择的翻译服务或模型路由；`autoTranslate` 控制自动发送，历史块始终手动。

## 兼容性与限制

实测 DSH `0.2.2-rc.5`，要求 `>=0.2.2-rc.5 <0.3.0`。插件依赖若干非公开接缝（`assistant-step` 原地替换、`groupPart` 双挂载、`turnProcess` 折叠、连接 RPC、volatile 配置 + `configEditor`），升级 DSH 后必须回归。翻译只覆盖思考框，不翻译正文。

全量测试 **155/155** 通过、无 skip。
